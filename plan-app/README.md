# お客様のプラン（1ファイルのアプリ）

RafaCoach のお客様アプリと同じ作りの、お客様に渡すプランのページです。管理画面とは別で、1つの `index.html` だけで動きます。
中身は Google Apps Script（`gas/Code.gs`）を通して、コーチの Google ドライブに保存します。編集は「編集」→ パスワード →「保存」だけで、お客様のページにもすぐ反映されます（HTMLの再アップロードは不要）。

## 保存先を用意する（最初に1回だけ）
1. https://script.google.com →「新しいプロジェクト」。名前は「畠山コーチング_プラン」など
2. 最初からある `コード.gs` の中身を全部消し、`gas/Code.gs` の中身を貼り付けて保存
3. 左の歯車「プロジェクトの設定」→ 一番下「スクリプト プロパティを追加」
   - プロパティ `PLAN_PASSWORD`、値 にコーチ用のパスワード → 保存
4. エディタに戻り、上の関数の選択で `setup` を選んで「実行」→ 権限の確認で自分のアカウントを選び「許可」
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」
   - 実行ログに「保存先フォルダ」「パスワード：設定済み」と出れば OK
5. 右上「デプロイ」→「新しいデプロイ」→ 歯車で「ウェブアプリ」
   - 次のユーザーとして実行：自分／アクセスできるユーザー：全員 →「デプロイ」
   - 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピー

## お客様のページにつなぐ（お客様ごとに1回）
1. お客様の `index.html` をブラウザで開き、下の「編集」
2. 「保存先（最初の1回だけ）」に、コピーした URL とプランID（例：`mizukami`）を入れる
3. 「反映して HTML を書き出す」→ 保存された `index.html` を Netlify Drop（https://app.netlify.com/drop）、または既存サイトの「Deploys」画面にドラッグ
4. 以後は、お客様のページで「編集」→ パスワード → 直す →「保存」だけ

## 新しいお客様のプランを作る
1. `template.html` を `index.html` という名前で保存し、ブラウザで開いて「編集」→ 名前・トレーニングなどを入れる
   - 「テキストから取り込む」に LINE の書き方（`Day1 (Push)` → `・種目（メモ）` → `40kgx8回`）を貼ると、トレーニングに分ける。【方針】【食事】【有酸素】の見出しの下の行は、それぞれのブロックへ
2. 上の「お客様のページにつなぐ」と同じ手順で、保存先とプランID（お客様ごとに別の ID）を入れて書き出し・公開
3. Netlify の「Project configuration → Change project name」で `名前-plan` などにして、URL をお客様に送る

## 注意
- 載せるのは事実だけ（いただいた情報）。中身のない項目はお客様の画面に出ない
- パスワードはコードにも HTML にも入れない（GAS のスクリプト プロパティだけ）。照合は GAS 側で行い、15分で10回間違えると15分保存できなくなる
- パスワードを変えるときは、スクリプト プロパティの `PLAN_PASSWORD` を書き換えるだけ（デプロイし直し不要）
- `Code.gs` を直したときは「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」（URL は変わらない）
- 保存先の URL がまだ入っていないページは、「編集」がパスワードなしで開く（保存はできず、書き出しだけ）
- `template.html` には個人情報を入れないこと（お客様ごとのファイルは、このリポジトリに入れない）
