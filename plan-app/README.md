# お客様のプラン（1ファイルのアプリ）

RafaCoach のお客様アプリと同じ作りの、お客様に渡すプランのページです。管理画面とは別で、1つの `index.html` だけで動きます。

## 新しいお客様のプランを作る
1. `template.html` を `index.html` という名前で保存する
2. ブラウザで開き、ページ下の「編集」→ 名前・トレーニングなどを入れる
   - 「テキストから取り込む」に LINE の書き方（`Day1 (Push)` → `・種目（メモ）` → `40kgx8回`）を貼ると、トレーニングに分ける。【方針】【食事】【有酸素】の見出しの下の行は、それぞれのブロックへ
3. 「反映して HTML を書き出す」→ 保存された `index.html` を Netlify Drop（https://app.netlify.com/drop）にドラッグ
4. Netlify の「Project configuration → Change project name」で `名前-plan` などにして、URL をお客様に送る

## 中身を直す（上書き）
1. お客様のページを開き、下の「編集」→ 直す →「反映して HTML を書き出す」
2. Netlify のそのサイトの「Deploys」画面に、書き出した `index.html` をドラッグすると上書きされる

## 注意
- 載せるのは事実だけ（いただいた情報）。中身のない項目はお客様の画面に出ない
- パスワードはない。「編集」は誰でも開けるが、ファイルを書き出してアップロードしない限り、お客様のページは変わらない
- `template.html` には個人情報を入れないこと（お客様ごとのファイルは、このリポジトリに入れない）
