# 顧客管理ダッシュボード（畠山祐輔さん）

ログインした瞬間に「今日・今週やること」「各お客様の進み具合」「約束が守れているか」が分かる管理画面です。
使うのは畠山さんと株式会社マルカトの担当者のみ。お客様は見ません。

- フロント：`public/`（HTML/CSS/JS の静的ファイル）
- API：Netlify Functions（`netlify/functions/api.mjs` → `/api`、本体は `netlify/lib/core.mjs`）
- データ：Netlify Blobs（Netlify に含まれる保存領域。無料プランで利用可。スプレッドシートや外部DBは使わない）
- グラフ：Chart.js（CDN・詳細画面を開いたときだけ読み込み）

すべて1つの Netlify サイトで完結します。

## 画面

RafaCoach の管理アプリと同じ作り（色の帯のヘッダー・数字のタイル・一覧の右に状態・タップで下からシート・下のナビ）。遅れは CAMEL 色（赤は使わない）。スマホのホーム画面に追加するとアプリのように使えます。

| 画面 | 内容 |

| ホーム | 進行中／入金待ち／終了／遅れ のタイル、今月の入金額、検索、「◯名があなたを待っています」、お客様から届いた（新着）、対応が必要（右に「チェックイン・3日」などの状態）、順調 |

| お客様の詳細 | 状態の帯、基本の表（進み具合・入金確認日・開始日・終了予定日・次のチェックインなど）、今週のタスク、フォーム添削／食事記録の＋−、お客様用リンク、LINEで送る、継続相談・終了、ヒアリングの回答、身体評価、最終評価、チェックインの履歴（体重グラフ＋週ごとのカード） |

### お客様用リンク（事前ヒアリング＋毎週のチェックイン）
- お客様の追加は「名前・LINE名・入金確認日（あとからでも可）」の3項目だけ。追加するとその人専用のリンク（`/form.html#鍵`）と案内文が自動ででき、「LINEで送る」「案内文をコピー」でそのまま送れる
  - 案内文は入金確認日の有無で書き出しが変わる。ヒアリング回答後はチェックインの依頼文になる
- 最初に開くと**事前ヒアリング**（4セクション14問・約5分。質問は `public/js/questions.js` で編集できる）。途中で閉じても端末に下書きが残る
  - 回答すると、管理画面で空欄の「目標」「チェックイン曜日」が回答から自動で入る（入力済みの値は上書きしない）
- 回答後は同じリンクが**毎週のチェックイン**になる。体重（複数回→週平均）、チェックシート7項目、体調、うまくいったこと、困っていること・質問を送れる
  - 送ると、その週の記録に自動で反映され「チェックイン」が済になる。ホームの「お客様からの提出」に3日間表示される
  - 今週と前週だけ送れる（先の週は不可）。同じ週は再送で上書き
- リンクで見られるのは本人の情報だけ。「リンクを作り直す」で古いリンクは無効になる

### 自動判定のルール
- 第n週 ＝ 開始日＋7×(n−1)日 〜 その6日後。終了予定日 ＝ 開始日＋83日（12週）
- チェックイン：その週のチェックイン曜日。過ぎて未記録なら遅れ
- 面談：週1回。前の週までに未実施、または今週の面談曜日を過ぎて未実施なら遅れ
- 週間レポート：その週の最終日までに未送付なら、翌週から遅れ
- 身体評価：開始時＝開始日、4・8・12週＝その週のチェックイン日（曜日未設定なら週の最終日）。過ぎて未実施なら遅れ
- 最終評価：11週目から表示し、終了予定日が期限
- 同じお客様・同じ項目の遅れは1行にまとめて表示（「ほかN週」）。タップで一番古い週を済にする
- スコア：5個以上「継続」／3〜4個「1つだけ改善」／0〜2個「計画をシンプルに」
- フォーム添削は上限2本、食事記録確認は目安3日を表示（警告はしない）。LINEサポートは表示のみ

## セットアップ

1. Netlify で「Add new project → Import an existing project」からこのリポジトリを接続する
   - ビルド設定は `netlify.toml` にあるので変更不要（公開フォルダ `public/`、関数 `netlify/functions/`）
2. 「Project configuration → Environment variables」で2つ追加する
   - `APP_PASSWORD`：ログイン用パスワード（長めの文章型を推奨。例：4語以上）
   - `TOKEN_SECRET`：ログイン状態の署名に使う秘密の文字列（40文字以上のランダムな英数字。人に伝える必要はない）
3. 「Deploys → Trigger deploy」で再デプロイする（環境変数を反映するため）
4. 公開された URL をスマホで開き、パスワードでログインできれば完了

## セキュリティ
- パスワードは Netlify の環境変数にだけ保存し、照合はサーバー側（Netlify Functions）で行う
- ログイン失敗が15分で10回に達すると、その後15分ログインを受け付けない
- ログイン後はサーバーが発行する HMAC 署名付きトークン（有効期限30日）で通信。ブラウザに保存されるので毎回の入力は不要
- スマホ紛失時などは `TOKEN_SECRET` を別の値に変えて再デプロイすると、全端末がログアウトされる。パスワード変更は `APP_PASSWORD` を変えて再デプロイ
- データは Netlify Blobs に保存され、ブラウザからは `/api` を通してしか読めない（ログイン必須）
- HTML・JS に個人情報は含まない。表示を速くするため、ログイン中の端末には最新データのコピーを保存し、ログアウトや期限切れで消去する
- 2人が同じお客様を同時に保存しても、上書きで消えないよう読み直してから保存する
- CSP・`X-Frame-Options`・`noindex` などのヘッダーを送る（`netlify.toml`）

## データとバックアップ
- お客様1人分（基本情報＋ヒアリング回答＋12週の記録）を1件として保存（キー `c/{id}`）
- お客様用リンクの鍵 → お客様の対応表（キー `k/{鍵}`）
- ホーム最下部の「バックアップ」で全データを JSON ファイルとしてダウンロードできる。月1回程度の保存を推奨

## プラン（画面内に表示）
3ヶ月（12週）／完全オンライン／30万円（税込33万円）／銀行振込・入金確認後に開始／初回カウンセリング60分／3ヶ月以降の継続は個別相談
