# 顧客管理ダッシュボード（畠山祐輔さん）

ログインした瞬間に「今日・今週やること」「各お客様の進み具合」「約束が守れているか」が分かる管理画面です。
使うのは畠山さんと株式会社マルカトの担当者のみ。お客様は見ません。

- フロント：`public/`（HTML/CSS/JS の静的ファイル）→ Netlify で公開
- データ：Google スプレッドシート ＋ Google Apps Script（`gas/Code.gs`）を API として使用
- グラフ：Chart.js（CDN・詳細画面を開いたときだけ読み込み）

## 画面

| 画面 | 内容 |
|---|---|
| ホーム | 遅れ・抜け（CAMEL色で最上部）／今日／今週のやること。行をタップでその場で「済」（6秒間「元に戻す」可）。右の「›」でお客様の詳細へ。下に進行中のお客様カード、入金待ち・継続相談・終了は折りたたみ |
| お客様の詳細 | 12週タイムライン（面談・チェックイン・レポート・評価の済／遅れ／これから）、約束の達成表、週ごとの記録入力（体重→週平均、チェックシート7項目→スコア、面談日、フォーム添削、食事記録確認、レポート送付、メモ）、推移グラフ、最終評価（11週目から表示）、基本情報 |
| 追加・編集 | 名前、LINE名、入金確認日、開始日（終了予定日を自動表示）、チェックイン曜日、面談曜日（任意）、目標、状態、メモ |

### 自動判定のルール
- 第n週 ＝ 開始日＋7×(n−1)日 〜 その6日後。終了予定日 ＝ 開始日＋83日（12週）
- チェックイン：その週のチェックイン曜日。過ぎて未記録なら遅れ
- 面談：週1回。前の週までに未実施、または今週の面談曜日を過ぎて未実施なら遅れ
- 週間レポート：その週の最終日までに未送付なら、翌週から遅れ
- 身体評価：開始時＝開始日、4・8・12週＝その週のチェックイン日（曜日未設定なら週の最終日）。過ぎて未実施なら遅れ
- 最終評価：11週目から表示し、終了予定日が期限
- 同じお客様・同じ項目の遅れは1行にまとめて表示（「ほかN週」）。タップで一番古い週を済にする
- スコア：5個以上「継続」／3〜4個「1つだけ改善」／0〜2個「計画をシンプルに」
- フォーム添削は上限2本、食事記録確認は目安3日を表示（警告はしない）。LINEサポートは表示のみ

## セットアップ

### 1. スプレッドシートと GAS
1. Google ドライブで新しいスプレッドシートを作る（**共有しない**）
2. 「拡張機能 → Apps Script」を開き、`gas/Code.gs` の内容を貼り付けて保存
3. 「プロジェクトの設定 → スクリプト プロパティ」で追加
   - `APP_PASSWORD`：ログイン用パスワード（長めの文章型を推奨。例：4語以上）
4. エディタで関数 `setup` を選んで実行し、権限を承認する（`Clients`・`Weeks` シートが作られる）
5. 「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**
   - 発行された URL（`https://script.google.com/macros/s/…/exec`）をコピー

> 「全員」にしても、パスワードと署名付きトークンがないとデータは返しません。スプレッドシート自体はオーナーしか開けません。

### 2. フロント
1. `public/js/config.js` の `GAS_URL` に上の URL を入れてコミット
2. Netlify でこのリポジトリを接続（`netlify.toml` で `public/` を公開、ビルド不要）
   - もしくは `public/` フォルダを Netlify Drop にドラッグ

### GAS を更新したとき
コードを直したら「デプロイ → デプロイを管理 → 編集 → バージョン：新バージョン」で同じ URL のまま更新します。

## セキュリティ
- パスワードはスクリプトプロパティにだけ保存し、照合は GAS 側（SHA-256 ＋ 定数時間比較）
- ログイン失敗が15分で10回に達すると、その後15分ログインを受け付けない
- ログイン後は GAS が発行する HMAC 署名付きトークン（有効期限30日）で通信。ブラウザに保存されるので毎回の入力は不要
- スマホ紛失時などは、GAS エディタで `resetAllSessions` を実行すると全端末がログアウトされる。パスワード変更はスクリプトプロパティを書き換えるだけ
- HTML・JS に個人情報は含まない。表示を速くするため、ログイン中の端末には最新データのコピーを保存し、ログアウトや期限切れで消去する
- Netlify から CSP・`X-Frame-Options`・`noindex` などのヘッダーを送る（`netlify.toml`）

## データ（スプレッドシート）
- `Clients`：お客様1人1行（基本情報、状態、身体評価の実施日 `eval0/4/8/12`、最終評価 `finalDone`・`finalPlan`）
- `Weeks`：お客様×週で1行（`weights` は JSON 配列、`checks` は7桁の 0/1）

## プラン（画面内に表示）
3ヶ月（12週）／完全オンライン／30万円（税込33万円）／銀行振込・入金確認後に開始／初回カウンセリング60分／3ヶ月以降の継続は個別相談
